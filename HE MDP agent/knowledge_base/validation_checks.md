# Validation Checks for Oncology CEA Models

Validation dimensions:
- Face validity
- Internal validity
- External validity
- Technical validation

Specific checks:
- Health-state occupancy checks
- OS/PFS consistency checks
- Cost and QALY plausibility checks
- Discounting implementation checks
- Traceability of assumptions/inputs to sources

Reviewer checklist:
- Are equations and state logic reproducible?
- Are key assumptions stress-tested?
- Are outputs clinically and economically plausible?
