# Utility Inputs in Oncology CEA

## Purpose
Utility inputs translate survival and morbidity outcomes into QALYs. Utility choices can materially influence incremental benefit estimates.

## Typical utility components
- Progression-free utility
- Progressed disease utility
- Adverse event disutilities
- Treatment-related utility effects when evidence supports inclusion

## Evidence options
- Trial-based utility data may be appropriate when robust and relevant.
- Literature-based values may be needed when trial data are incomplete.
- Mapping assumptions may be considered when direct preference-based measures are unavailable.

EQ-5D-based evidence may be preferred where appropriate and available, but suitability should be judged by context.

## Implementation considerations
- Apply utilities by health state, time-to-death, or both where justified.
- Consider age adjustment if required by methodology and evidence context.
- Keep source hierarchy transparent and note transferability concerns.

## Common HTA / ERG / EAG concerns
- Utility sources not aligned to population or setting.
- Mapping assumptions insufficiently justified.
- Disutility duration or incidence assumptions not transparent.

## Questions the HE MDP Agent should ask
- Are trial-based utilities available and decision-relevant?
- If mapped utilities are used, what validation is available?
- Should utilities vary by treatment, health state, or time-to-death?
- Which utility assumptions need scenario testing?

## MDP implications
The MDP should include utility source hierarchy, application rules, and scenario plans for key utility uncertainties.

## Example wording
"Utilities will be applied using health-state values with adverse event disutilities where supported by evidence. Alternative utility sources and mapping assumptions should be assessed in scenario analysis if transferability or methodological uncertainty remains."
