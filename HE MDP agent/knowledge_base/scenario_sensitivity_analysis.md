# Scenario and Sensitivity Analysis Planning

## Purpose
Uncertainty analysis evaluates robustness of conclusions and identifies key drivers of decision uncertainty.

## Core components
- Deterministic sensitivity analysis (DSA) for parameter influence.
- Probabilistic sensitivity analysis (PSA) for joint parameter uncertainty.
- Scenario analysis for structural and methodological uncertainty.

## Typical oncology scenarios
- Survival extrapolation alternatives
- Treatment waning assumptions
- Cure fraction assumptions
- Utility source/application alternatives
- Cost source and costing-method alternatives
- Subsequent therapy assumptions
- Time horizon alternatives
- Discount-rate alternatives
- Perspective variants, where relevant

## Structural versus parameter uncertainty
- Parameter uncertainty may be addressed in DSA/PSA.
- Structural uncertainty should be considered in targeted scenario analysis with clear rationale.

## Common HTA / ERG / EAG concerns
- Scenario set is too narrow for key uncertainties.
- Structural assumptions not stress-tested.
- Lack of transparency on parameter distributions or ranges.

## Questions the HE MDP Agent should ask
- Which assumptions are likely decision-sensitive?
- Which scenarios are mandatory for stakeholder credibility?
- Are structural alternatives needed for model structure or survival?
- Which uncertainty analyses are feasible in the planned timeline?

## MDP implications
The MDP should pre-specify DSA, PSA, and prioritized scenario sets with rationale and expected interpretation approach.

## Example wording
"Uncertainty analysis will include DSA and PSA for parameter uncertainty, plus prespecified structural scenarios (survival extrapolation, treatment waning, utility and cost source alternatives, and subsequent therapy assumptions) where decision impact is expected."
